# Ebisu — Local-First Coding Agent TUI

## Installation

Install the required dependencies:

```bash
python -m pip install textual psutil
```

## Run

Start the application:

```bash
python terminal.py
```

## Configuration

The application location can be configured locally using the `EBISU_LOCATION` environment variable.

### Windows PowerShell

```powershell
$env:EBISU_LOCATION="Thiruvananthapuram, India"
python terminal.py
```

### Linux

```bash
EBISU_LOCATION="Thiruvananthapuram, India" python terminal.py
```
